# Press Play

Проект использует Nuxt 4, Vue 3, строгий TypeScript, npm, SCSS и `nuxt-svgo`. Соглашения адаптированы из `main-site-service` (CHESU) для сайта аренды.

## Разработка

- Перед правкой прочитай этот файл, затронутый модуль и соседние компоненты. Используй существующие `Ui*` компоненты и токены до создания новых.
- Имена Vue-файлов в kebab-case. В шаблонах используй автоимпортированные PascalCase-компоненты и `NuxtLink` для внутренних маршрутов.
- Компоненты используют `<script setup lang="ts">`, типизированные props и события. Страница управляет состоянием запроса. Общие компоненты получают данные через props и сами определяют внутренний адаптив.
- Стили компонентов пишутся в scoped SCSS с BEM-классами. Токены и миксины находятся в `app/assets/scss/abstracts`. Для адаптива используй CSS, сохраняй видимый фокус и поддержку `prefers-reduced-motion`.
- Аренда согласуется в WhatsApp. Контакт задаётся через `NUXT_PUBLIC_WHATSAPP_NUMBER`, а ссылка открывает черновик сообщения.
- После правок проверяй `npm run build`, `npm run typecheck` и `npm run lint`.
