# Press Play

Сайт аренды PlayStation 5 на Nuxt 4. На главной два перехода: заявка на аренду и справочник. В справочнике есть текст на русском, правила пользования и видео официальных каналов PlayStation на английском.

## Запуск

Нужен Node.js 22.18 или новее.

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm run build
```

`npm run build` собирает Worker для Sites в `dist/`. Sites применяет SQL-миграции из `drizzle/` и подключает D1 как `DB`. Для обычного Node.js используйте `npm run build:node` и `npm run preview` либо `docker compose up -d --build`. Контейнер слушает `127.0.0.1:3000` и хранит SQLite в томе `orders`. Локальный Nuxt хранит заявки в `.data/orders.sqlite`. Путь можно изменить через `NUXT_ORDER_DATABASE_PATH`.

## Заявки

Форма сохраняет даты, имя, контакт, комментарий и время отправки. Даты начала проверяются по московскому времени. Успешный ответ выдаёт номер сохранённой заявки. Цена, доступность, комплектация, способ получения и оплата согласуются с клиентом после заявки. Повтор отправки с тем же идентификатором возвращает тот же номер.

На Sites владелец может просмотреть таблицу `orders` через инструменты работы с базой Site. Для локального SQLite можно использовать `sqlite3 -readonly .data/orders.sqlite` и запрос `SELECT * FROM orders ORDER BY created_at DESC;`. Уведомления о новых заявках не настроены.

Тексты справочника и ссылки на видео находятся в `app/composables/use-guide-data.ts`.
