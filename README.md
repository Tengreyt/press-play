# Press Play

Сайт аренды PlayStation 5 на Nuxt 4. На главной два перехода: аренда через WhatsApp и справочник. В справочнике есть текст на русском, правила пользования и видео официальных каналов PlayStation на английском.

## Запуск

Нужен Node.js 22.18 или новее. Для проверки кнопки WhatsApp укажи в `.env` значение `NUXT_PUBLIC_WHATSAPP_NUMBER` с кодом страны. Приложение показывает этот номер на странице аренды.

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm run build
```

`npm run build` собирает Worker для Sites в `dist/`. Номер опубликованного сайта задаётся переменной `NUXT_PUBLIC_WHATSAPP_NUMBER` в настройках Sites. Для обычного Node.js используй `npm run build:node` и `npm run preview` с переменной в окружении либо `docker compose up -d --build`. Контейнер слушает `127.0.0.1:3000`.

## Аренда

Кнопка на странице аренды открывает чат с черновиком сообщения. Клиент дописывает даты и отправляет сообщение сам. Доступность, цена и передача согласуются в переписке. Историю заявок предыдущей версии можно просмотреть через таблицу `orders` в Sites.

Тексты справочника и ссылки на видео находятся в `app/composables/use-guide-data.ts`.
